Simple iOS Task Manager App with UIKit (storyboard) showing work with tables, custom cell and data. 

#Tech Stack: 
- Swift
- UIKit
- Git

#Architecture
- MVC 

#Data storage 
- UserDefaults

#Features
- Two task types
- Add new tasks
- Edit existing tasks
- Mark tasks as completed with a single tap
- Move tasks within a type (drag and drop)
- Delete tasks with a swipe
- Empty state handling
- Persistent storage
